# DevOps-Lab04 — IT Care

## ภาพรวม

IT Care เป็นหน้าเว็บตัวอย่างสำหรับบริการ IT Support ช่วยให้ผู้ใช้งานดูบริการและกรอกแบบฟอร์มแจ้งปัญหาไอทีได้ในหน้าเดียว พัฒนาด้วย HTML, CSS และ JavaScript แบบพื้นฐาน โดยไม่ต้องติดตั้งไลบรารีหรือเครื่องมือเพิ่มเติม

## ความสามารถ

- แสดงหน้าแนะนำบริการและตัวอย่างรายการแจ้งปัญหา
- แสดงประเภทบริการด้านคอมพิวเตอร์และอุปกรณ์ เครือข่าย และโปรแกรมหรือบัญชีผู้ใช้
- มีแบบฟอร์มแจ้งปัญหาพร้อมตรวจสอบช่องที่จำเป็นก่อนส่ง
- แสดงข้อความยืนยันหลังส่งแบบฟอร์ม
- รองรับหน้าจอขนาดต่าง ๆ ด้วย Responsive CSS

> **ข้อจำกัดของตัวอย่าง:** แบบฟอร์มทำงานเฉพาะในเบราว์เซอร์ ข้อมูลไม่ได้ถูกบันทึก ส่งให้ทีมงาน หรือเชื่อมต่อกับระบบรับแจ้งจริง ข้อความยืนยันเป็นเพียงตัวอย่าง ส่วนรายการแจ้งปัญหาบนหน้าแรกเป็นข้อมูลประกอบหน้าตาเว็บแบบคงที่

## โครงสร้างไฟล์

```text
.
├── index.html   # โครงสร้างหน้าเว็บ สไตล์ และ JavaScript สำหรับแบบฟอร์ม
└── README.md    # คำอธิบายโปรเจกต์และวิธีใช้งาน
```

## วิธีเปิดใช้งาน

ไม่ต้องติดตั้ง dependencies:

1. ดาวน์โหลดหรือ clone โปรเจกต์
2. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์

หากต้องการเปิดผ่าน local web server สามารถใช้ Live Server ใน VS Code หรือเครื่องมือ HTTP server ที่มีอยู่ได้เช่นกัน ฟอนต์ Kanit และ Prompt โหลดจาก Google Fonts; หากไม่มีอินเทอร์เน็ต เบราว์เซอร์จะใช้ฟอนต์สำรองที่กำหนดไว้

## การทำงานของแบบฟอร์ม

ช่องชื่อผู้แจ้ง ช่องทางติดต่อ ประเภทและระดับความเร่งด่วน รวมถึงรายละเอียดปัญหาเป็นช่องบังคับ เมื่อกดส่ง หน้าเว็บจะตรวจสอบข้อมูลด้วย validation ของเบราว์เซอร์ จากนั้นแสดงข้อความยืนยันและล้างข้อมูลในฟอร์ม โดยไม่ได้ส่งข้อมูลออกจากเครื่อง

หากนำไปใช้งานจริง ต้องเชื่อมต่อแบบฟอร์มกับ backend หรือบริการรับแจ้งปัญหา และกำหนดการจัดเก็บและคุ้มครองข้อมูลผู้แจ้งอย่างเหมาะสม
